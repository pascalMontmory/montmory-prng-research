# Édition scientifique publique

[Français](publication.md) · [English](en/publication.md)

Ce dépôt publie le dossier scientifique des travaux de Pascal Montmory pour ENINCA CONSULTING. Il a été préparé à partir de la révision de recherche `4d8a1a9316f6672d32949e8a4d7022006433fdcf`, le 21 octobre 2026, avec un historique Git neuf. Le dépôt source privé et son historique restent privés ; aucun document juridique privé n'est inclus.

Les **884 fichiers scientifiques importés** conservent leurs octets et empreintes SHA-256 enregistrés. Les sources, données de mesure, journaux historiques, notices des tiers et kits embarqués dans les notebooks sont conservés. La documentation, les URL de clonage et le contrôleur des traductions ont été adaptés à cette édition publique. Le [registre des traductions](translations.json) public recense uniquement les éditions de lecture incluses.

La visibilité publique n'active aucune nouvelle licence générale sur les contributions originales. La [notice des droits](../LICENSE.fr.md) et les [notices des tiers](../THIRD_PARTY_NOTICES.fr.md) décrivent leurs périmètres respectifs.

Commencer par les [résultats](results.md), la [méthodologie](methodology.md), la [reproduction](reproduce.md) et les [notebooks TPU](../notebooks/README.fr.md). La publication ne revendique aucun nouveau benchmark matériel natif. Citer ce dépôt public et le commit public exact utilisé.

```bash
python3 scripts/check_repository.py
python3 scripts/check_translations.py
python3 scripts/check_reference.py
```
