\section*{Objective}
This document summarizes the formal validation of the proprietary random number generator \textbf{PRNG\_MONTMORY\_CTACM}, developed by EnInca Consulting, using the \textit{TestU01} framework (version 1.2.3). The objective is to certify the statistical quality through the \textit{SmallCrush}, \textit{Crush}, and \textit{BigCrush} test batteries.

\section*{Confidentiality}
The internal algorithmic structure and transformations of \textbf{PRNG\_MONTMORY\_CTACM} are proprietary and available only under non-disclosure agreement (NDA). This report discloses the validation environment and outcomes without revealing implementation details.

  \item Streams are deterministic and reproducible across CPU and GPU (Metal) back-ends.
